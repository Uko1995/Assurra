Escrow Lifecycle

Initialize and manage escrow transactions. All write operations require an X-Idempotency-Key to prevent duplicate processing.

curl -X POST https://api.assurra.com/api/v1/escrow \
  -H "X-API-Key: your_key_here" \
  -H "X-Idempotency-Key: "$(uuidgen) \
  -d '{
    "amount": 75000,
    "currency": "NGN",
    "merchant_ref": "ORD-102",
    "callback_url": "https://your-site.com/webhook"
  }'
POST /escrow/{ref}/ship

Update status to 'shipped' with trackingNumber.

POST /escrow/{ref}/confirm

Buyer confirmation to release funds to merchant.

POST /escrow/{ref}/dispute

Initiate a dispute resolution process for a specific escrow transaction.
